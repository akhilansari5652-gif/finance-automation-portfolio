# Finance Operations Automation Portfolio

A portfolio of practical finance automation solutions built to reduce repetitive work, improve accuracy and create review-ready outputs.

## About Me

I am a Dubai-based finance and automation professional with an ACCA background and practical experience in accounting operations, payment settlements, reconciliations and ERP preparation.

I build user-friendly tools using Python, Excel and automation technologies, with human review maintained for sensitive finance activities.

## Automation Suite

The suite demonstrates seven finance workflows:

1. Tabby Settlement to ERP
2. AMEX Settlement to ERP
3. Tamara Settlement to ERP
4. Credit Flow Settlement to ERP
5. Bank Transaction Marking
6. Credit Card Settlement Reconciliation
7. DSR Collection from Outlook

## What the Solution Does

* Processes settlement and transaction files
* Validates and standardizes finance data
* Maps stores, entities and accounting information
* Prepares ERP-ready upload files
* Reconciles settlement records against bank transactions
* Identifies unmatched items and exceptions
* Produces downloadable Excel reports
* Provides a clean interface for non-technical users

## Technology

* Python
* Pandas
* OpenPyXL
* Streamlit
* Microsoft Excel
* Outlook automation
* Finance and accounting rules

## Control and Data Safety

The portfolio demonstration uses synthetic data only. Real company information, credentials, banking details and confidential processing files are not included.

Automation prepares and validates the output, while final review and ERP posting remain under human control.

## Business Value

These solutions are designed to:

* Reduce repetitive manual work
* Improve processing consistency
* Identify exceptions quickly
* Reduce avoidable errors
* Create clear audit trails
* Allow finance teams to focus on review and decision-making
